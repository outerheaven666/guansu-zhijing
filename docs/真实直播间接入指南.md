# 真实直播间接入指南（测试号 → 正式经营）

> 目标：今天就能把互动台架进真实直播间，用真实反馈驱动优化。
> ⚠ 灰色路径仅限**测试号**验证流程，有封号风险；正式经营必须切换到抖音开放平台官方能力。

---

## 一、今天就能跑的接入流程（约 20 分钟）

### 1. 启动本机直播服务

```bash
cd app
npm run live        # 自动构建并启动，监听 7210 端口
```

启动后：
- 互动台页面：`http://localhost:7210/live/`（OBS 浏览器源指向这里）
- 礼物事件接收口：`POST http://localhost:7210/api/gift`
- 每场礼物数据自动落盘：`app/data/live-YYYY-MM-DD.jsonl`

### 2. 安装礼物连接器（油猴脚本）

1. 浏览器安装 Tampermonkey 扩展；
2. 新建脚本，粘贴 `connector/douyin-gift-connector.user.js` 全文并保存；
3. 用**测试号**打开自己的直播间页面（`live.douyin.com/你的房间号`）；
4. 右下角出现「观俗连接器 ●」角标即运行中；
5. 出现脚本未识别的礼物时，看控制台 `[未映射]` 日志，把礼物名和抖币价值补进脚本顶部的 `GIFT_TABLE`。

### 3. 自测

- 互动台切到「对接模式」，确认顶部状态为「本地直播服务已连接」；
- 用另一个账号（或让朋友）在直播间刷一个小心心 → 上屏区应在 2 秒内生成专属节气签；
- 也可手动模拟真实事件：

```bash
curl -X POST http://localhost:7210/api/gift -H "Content-Type: application/json" -d "{\"nickname\":\"测试观众\",\"giftName\":\"墨镜\",\"diamond\":99}"
```

### 4. OBS 上屏

OBS → 来源 + → 浏览器 → URL 填 `http://localhost:7210/live/` → 截取右侧「OBS 上屏区」卡片 → 进直播画面。

### 5. 直播话术（合规版）

- 「刷小心心，领一张写着你名字的今日节气签。」
- 「刷墨镜以上，抽一条本周主题的经典引文签，带出处和小实验。」
- 禁说：「测运势」「看姻缘」「改命」「灵验」。

## 二、真实反馈 → 优化闭环（每周 30 分钟）

每场直播后数据都在 `app/data/live-YYYY-MM-DD.jsonl`，一行一个礼物事件：

```json
{"id":"dy-...","nickname":"青梅煮酒","giftName":"墨镜","diamond":99,"at":1753430000000,"source":"douyin-userscript"}
```

每周复盘四个问题：

1. **分档分布**：t1:t2:t3:t4 的比例是多少？全是 t1 说明话术只推了最低档，把 t2「执镜签」的权益讲具体；
2. **转化漏斗**：场观 → 发言 → 首刷 → 复刷，断在哪一环；
3. **排队体验**：jsonl 时间戳间隔 < 展示时长说明有排队，考虑调短 t1 上屏时间或合并连击；
4. **主题反馈**：本周执镜主题哪类礼物多，下周主题就往那个方向靠（主题=选品）。

把结论记进 `docs/直播复盘/` 下的周记（模板见下），连续四周后再决定是否投入官方资质与 Pro 订阅开发。

### 周记模板

```markdown
## 第 N 周（M月D日–M月D日）
- 场次 / 总场观 / 总抖币 / 估算分成：
- 分档分布 t1:t2:t3:t4：
- 最有效的口播话术：
- 弃看/弃刷的明显时刻：
- 下周改动（只改一件）：
```

## 三、什么时候切官方路径

满足任意两条即值得启动企业资质申请（1–2 周审核）：

- 连续 4 周每周直播 ≥ 4 场；
- 单场估算分成 ≥ ¥150；
- 出现 ≥ 2 个 t4（典藏礼）打赏。

官方路径：企业主体注册抖音开放平台 → 创建「直播小玩法/互动工具」应用 → 审核通过后，
把礼物事件回调 POST 到 `http://localhost:7210/api/gift`（或届时迁移到云端服务），页面端无需任何改动。
