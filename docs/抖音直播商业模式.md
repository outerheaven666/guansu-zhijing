# 抖音直播 × 观俗·执镜：打赏分档驱动的差异化文化内容服务

> 版本 v1 · 2026-07
> 一句话：**刷礼物是付费方式，交付物是文化内容，不是预测。**

---

## 1. 模式概述

观众在抖音直播间刷礼物 → 「直播互动台」（`live/index.html`）实时接收礼物事件 →
按礼物价值分档自动生成**带观众昵称的专属文化卡** → 通过 OBS 浏览器源上屏展示，
观众截图/长按带走。全流程自动化，主播只需讲解与互动。

```
抖音直播间礼物 ──(礼物事件适配器)──> 直播互动台 ──> 分档规则引擎
                                              │
                          ┌───────────────────┼───────────────────┐
                     节气签（t1）          执镜签（t2）       双镜/典藏签（t3/t4）
                          └───────────────────┴───────────────────┘
                                              └──> OBS 上屏展示 → 观众截图带走
```

设计逻辑（定价三轴）：

- **价值指标**：礼物价值——平台原生支付单位，零支付接入成本、零审核风险（打赏不走商户类目）。
- **包装**：档位间差异是「内容深度+展示时长+身份权益（知音榜）」，不是「算得更准」。
- **价格点**：t1 做人气（几乎人人刷得起），t2 做转化主力（一杯蜜雪冰城），t3/t4 做收入大头（直播间收入 80% 通常来自 <20% 的高价值观众）。

## 3. 分成与单位经济

- 1 元 ≈ 10 抖币；个人主播分成通常约为打赏流水的 **50%**（平台分成后；签公会另按比例，通常再让渡 10–30% 换流量扶持）。
- 内容生成边际成本 ≈ 0（全部本地 Canvas 生成，无服务器、无 API 费）。
- 粗算（🔴 假设）：场均观看 2,000 人，打赏转化 3%，客单 60 抖币 → 60 单 × 60 币 = 3,600 币 ≈ ¥360 流水/场，主播到手 ≈ ¥180/场；每周 5 场 ≈ ¥900/周。真正起量依赖 t3/t4 大额打赏与场观增长。
- 二级漏斗：卡片页脚与口播引导关注「观俗·执镜」站点 → 执镜 Pro 订阅（见 README 商业模式），直播获客、订阅沉淀。

## 4. 合规底线（不可谈判）

1. **不做预测类服务**。抖音社区规范明确打击宣扬封建迷信内容，「刷礼物算命/测运势」是封号高危行为；本模式所有交付物为节气民俗、经典引文（附出处）、自我叙事练习，属文化科普内容。
2. **口播话术纪律**：不承诺「改运」「灵验」「消灾」；标准话术示例："这是一张文化签，给你一个看问题的新角度。"
3. **未成年人**：直播间须按平台要求提示「未成年人禁止打赏」。
4. **礼物数据获取**：正式经营使用抖音开放平台官方「直播小玩法/互动工具」能力（需企业主体+审核）；生态中非官方弹幕抓取库违反平台协议、有封号风险，仅限测试号验证流程。
5. 若直播内容涉及医疗健康话题（五运六气卡），必须保留「医学史视角，不构成医疗建议」标注。

## 5. 技术对接

互动台提供两种事件注入方式（见 `live/index.html` 对接模式面板）：

- `BroadcastChannel('gz-live-gifts').postMessage({ type:'gift', id, nickname, giftName, diamond })`
- `window.__gzLiveGift({ id, nickname, giftName, diamond })`

事件幂等（按 id 去重）、队列上限 50、单卡轮播展示。OBS 添加「浏览器源」指向
`https://outerheaven666.github.io/guansu-zhijing/live/`，截取右侧上屏区即可。

## 6. 冷启动打法

1. **内容定位**：「每天一个节气/一句经典」文化慢直播，画面就是互动台上屏区，主播讲解当令节气民俗。
2. **钩子**：免费弹幕扣「1」抽节气签（人工演示），刷礼物必得——制造第一笔打赏。
3. **节奏**：每周一个执镜主题（周一选择、周二压力……），t2 签品随主题换，制造复刷理由。
4. **知音榜**：典藏礼名字留在下周直播背景里，身份权益驱动大额打赏。
5. **复盘**：埋点已记录每场礼物事件与分档分布（localStorage 缓冲，后续接后端汇总）。
